# zx打卡

一个手机优先的多人减肥打卡网页，可记录体重（斤）、运动、饮食和早晚刷牙状态。用户可以注册账号，并通过 8 位用户码只读查看其他用户的打卡记录。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 数据与账号说明

- 账号密码使用加盐 `scrypt` 哈希保存，登录状态使用 HttpOnly Cookie。
- 打卡记录保存在 Netlify Blobs 云存储中，可跨设备访问。
- 每位用户拥有独立用户码；只有本人可编辑记录，其他登录用户通过用户码只读查看。
- 首次登录可将旧版浏览器本地记录导入云端。
